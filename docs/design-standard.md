# Sports Lab 介面美化基準

2026-11-16，使用 frontend-design 技能整理；延續使用者已確認的淺色、簡潔、大字體、中英文球員姓名風格。

## 視覺設定

| 用途 | 顏色 |
| --- | --- |
| 頁面底色 | #f2f6fa |
| 內容底色 | #ffffff |
| 主要文字 | #183950 |
| 次要文字 | #496779 |
| 強調與操作 | #087e75 |
| 分隔線 | #cedce7 |

使用本機繁體中文字體 PingFang TC／Microsoft JhengHei，無額外網路字型。姓名約 20px、核心數字 20–26px、資料標籤 12–13px；數字使用等寬數字排版以便比較。

## 版面

球員卡依序為頭像姓名、球隊／基本資訊、評分、四項重點數據、完整資料入口、可展開來源。轉隊維持一人一排、現在往前的橫向歷程，手機可橫向捲動；目前球隊及背號以青綠色區分。排行榜使用清楚的欄位背景與交錯行底色，不增加額外圖示或裝飾動畫。

手機聯盟切換維持兩欄，球員卡為單欄；篩選器可折行、輸入框不超出容器。鍵盤焦點清楚可見，主要控制項高度至少 44px；尊重 reduced-motion。

## 實作與範圍

樣式集中在 public/design-polish.css，以 body.sports-polish 限定作用範圍；只在主網站及轉隊頁最後載入，覆寫優先於既有樣式。保留來源、警示、統計欄位、排名公式及資料收集行為。

初步方案曾考慮卡片動畫及額外首頁視覺，但依使用者已確認的設計方向，採既有淺色介面細節調整，不引入新主題。不要為套用技能而改變網站內容或重做風格。

本次建置與 201 項現有測試通過；瀏覽器預覽逾時，尚未完成實際桌面及手機畫面檢查。測試通過不等於視覺驗收。
