安裝手機版
Install Sports Lab

把 Sports Lab 加入手機主畫面，從圖示直接開啟賽事、球員資料和排行榜。

iPhone / iPad

  1. 使用 Safari 開啟 Sports Lab。
  2. 點下方的「分享」按鈕，再選「加入主畫面」。
  3. 如果看到「以網頁 App 開啟」，將它打開，然後點「加入」。

Android

  1. 使用 Chrome 開啟 Sports Lab。
  2. 點右上角的「⋮」選單，選「安裝應用程式」或「加到主畫面」。
  3. 依照手機提示完成安裝。

使用說明

本服務需要網路連線，賽事和球員數據依網站資料來源與更新時間顯示。選單名稱可能因手機和瀏覽器版本不同而略有差異。
