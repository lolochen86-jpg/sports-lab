安裝留言

安裝手機版

開啟 Sports Lab

iPhone / iPad

Safari → 分享 → 加入主畫面

安裝步驟
  1. 用 Safari 開啟 Sports Lab。
  2. 點「分享」→「加入主畫面」。
  3. 若看到「以網頁 App 開啟」，開啟後點「加入」。

Android

Chrome → ⋮ → 安裝

安裝步驟
  1. 用 Chrome 開啟 Sports Lab。
  2. 點「⋮」→「安裝應用程式」或「加到主畫面」。
  3. 依照提示完成。
使用說明

Sports Lab 需要網路。數據依原網站來源與更新時間顯示，選單名稱依手機及瀏覽器版本而異。
